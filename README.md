# Oceània · Potències i arrels

Aplicació educativa en català per a 1r d’ESO, ambientada en el món submarí.

Cinc escaperooms de potències amb nombres naturals, deu proves per missió,
exercicis nous en cada intent, dues ajudes, sons i progrés visual.
Les arrels estan pendents d’implementar.

## Ús

Obre `index.html` o la web publicada amb GitHub Pages. No requereix instal·lació.

## Privacitat i progrés

El nom, les respostes i el progrés es desen només al navegador de l’alumne.
No s’envien al servidor ni a GitHub. Els informes PDF i les còpies del progrés
es generen al dispositiu. No hi ha analítica ni serveis externs.

Abans de canviar de navegador, exporta el progrés i importa’l al nou navegador.
El progrés de la versió local no es transfereix automàticament a la web publicada.

## Funcionament

Calen vuit proves superades per assolir cada missió. Acabar les deu proves
permet continuar a la següent. Cada prova dona 10 punts sense ajudes,
7 amb una ajuda, 4 amb dues o 0 si no se supera després de tres intents.
